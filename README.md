# Missão Espacial: Estação Orbit

Módulo de controle da estação espacial focado em gerenciamento de vida e testes de ambiente.

## 🛠️ Camadas do Ambiente
- **develop:** Ambiente de desenvolvimento ativo para codificação e novas features.
- **stage:** Ambiente de homologação para testes integrados e validações de qualidade.
- **main:** Ambiente de produção contendo apenas código estável e homologado.
